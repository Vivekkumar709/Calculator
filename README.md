# 🧮 Calculator (HTML, CSS, JavaScript)

A sleek and functional calculator built using **HTML**, **CSS**, and **JavaScript**.  
This project performs basic arithmetic operations with a clean, modern UI and responsive design.

---

## 🚀 Features
- ✅ Basic arithmetic operations — Addition, Subtraction, Multiplication, Division, Modulus  
- 🧹 Clear (`AC`) and Delete (`DEL`) functionality  
- 🟠 Responsive design with a glowing UI  
- ⌨️ Keyboard-like interface using clickable buttons  
- ⚡ Real-time calculation using `eval()` for simplicity
